# server-fundacion-formar-web

## Descripción

Esta es una aplicación para el servidor de la Fundación Formar.

## Requerimientos

- Node.js v14 o superior
- pnpm v6 o superior

## Instalación

Para instalar las dependencias del proyecto, ejecuta el siguiente comando en la raíz del proyecto:

```bash
pnpm install
```

## Scripts

- `pnpm start`: Inicia la aplicación con `nodemon`.
- `pnpm build`: Copia los archivos necesarios al directorio `dist` para el despliegue.
- `pnpm dev`: Inicia la aplicación en modo desarrollo.
- `pnpm preview`: Previsualiza el proyecto ejecutando el servidor desde el directorio `dist`.

## Uso

Para iniciar la aplicación en modo desarrollo, ejecuta:

```bash
pnpm dev
```

Para compilar el proyecto, ejecuta:

```bash
pnpm build
```

Para previsualizar el proyecto después de compilarlo, ejecuta:

```bash
pnpm preview
```
